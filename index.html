    Format yang didukung
    
      
    Setiap format ditangani secara khusus agar struktur dan gayanya tetap rapi.
    
    
    
    
    
      
    
        
    
        
    Word (.docx)
    
        
    Paragraf, tabel, gambar, header/footer, dan gaya teks dipertahankan. Nama file hasil tetap sama dengan akhiran bahasa.
    
      
    
      
    
        
    
        
    PDF
    
        
    Dua mode: pertahankan tata letak (halaman asli + teks baru) atau susun ulang teks menjadi PDF yang bersih.
    
      
    
      
    
        
    
        
    PowerPoint (.pptx)
    
        
    Semua slide dan catatan pembicara diterjemahkan. Desain, gambar, dan animasi tidak berubah.
    
      
    
      
    
        
    
        
    Excel (.xlsx)
    
        
    Sel, rumus, dan format angka aman. Hanya teks pada sel dan komentar yang diterjemahkan.
    
      
    
      
    
        
    
        
    Teks, Markdown, CSV
    
        
    Baris kosong dan struktur file tetap terjaga. Blok kode pada Markdown dilewati.
    
      
    
      
    
        
    
        
    Subtitle & HTML
    
        
    SRT/VTT: nomor dan timestamp tidak disentuh. HTML: tag dan atribut tetap utuh.

    Pertanyaan yang sering diajukan
    
    
    
    
    
      
    
        Apakah benar-benar gratis dan tanpa batas?
        
    Ya. Aplikasi ini berjalan sepenuhnya di browser Anda dan tidak memakai server sendiri, sehingga tidak ada biaya per halaman. Satu-satunya batas adalah ukuran file (60 MB) agar browser tidak kehabisan memori.
    
      
    
      
    
        Apakah file saya diunggah ke server?
        
    Tidak. Dokumen dibaca dan ditulis ulang di perangkat Anda. Hanya potongan teks yang dikirim ke endpoint publik Google Translate untuk diterjemahkan — sama seperti saat Anda membuka Google Translate.
    
      
    
      
    
        Apakah format dan gambar tetap utuh?
        
    Untuk DOCX, PPTX, XLSX, dan HTML, hanya teks yang diganti, sehingga gambar, tabel, warna, dan tata letak tetap. Untuk PDF, pilih mode “Pertahankan tata letak” agar halaman asli dipertahankan dan teks terjemahan ditimpa di posisinya.
    
      
    
      
    
        Kenapa hasil PDF kadang kurang rapi?
        
    PDF tidak menyimpan struktur paragraf, jadi posisi teks ditebak dari koordinat. Jika hasilnya kurang nyaman dibaca, gunakan mode “Susun ulang teks” untuk PDF yang mengalir dari atas ke bawah. Hasil PDF berupa halaman gambar beresolusi tinggi, sehingga teksnya belum bisa dipilih atau dicari; DOCX, PPTX, XLSX, dan HTML tetap berupa teks asli yang bisa diedit.
    
      
    
      
    
        Bahasa apa saja yang didukung?
        
    Lebih dari 80 bahasa, termasuk Indonesia, Inggris, Jepang, Korea, Mandarin, Arab, Hindi, Spanyol, Prancis, Jerman, dan bahasa-bahasa daerah seperti Jawa dan Sunda.
    
      
    
      
    
        Bisakah saya men-deploy versi saya sendiri?
        
    Bisa. Seluruh kode tersedia di GitHub dan aplikasi ini adalah situs statis — cukup aktifkan GitHub Pages pada repositori Anda. Petunjuk lengkap ada di README.
